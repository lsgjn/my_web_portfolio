# 02. 디자인

## 1. 방향
- 컨셉: **다크 기반 + 단일 포인트 컬러**, 게임 개발자 느낌의 개발 도구/에디터 분위기. 과한 효과 없이 콘텐츠(영상·스크린샷)가 돋보이도록 절제
- 톤: 기술적이고 깔끔하지만 차갑지 않게. 모노스페이스 폰트를 라벨/태그에 포인트로 사용
- 라이트 모드: 1차 범위에서는 제외(다크 단일). 필요하면 이후 토큰 교체로 확장

## 2. 컬러 토큰 (Tailwind 4 `@theme`으로 정의 예정)
| 토큰 | 값 | 용도 |
|---|---|---|
| bg | #0F1117 | 페이지 배경 |
| surface | #171A23 | 카드, 섹션 |
| surface-2 | #202533 | 썸네일 자리, hover |
| border | #262A36 | 구분선, 카드 테두리 |
| text | #E8EAF0 | 본문/제목 |
| muted | #8B93A7 | 보조 텍스트 |
| accent | #6EE7C8 | CTA, 링크, 강조 (한 가지만 사용) |

규칙: accent는 화면당 주요 CTA와 링크에만 사용, 태그/배지는 surface-2 + muted로 통일

## 3. 타이포그래피
- 본문/제목: Pretendard (한/영 모두 대응)
- 라벨/태그/날짜/코드: JetBrains Mono (또는 D2Coding)
- 크기: 본문 16px, 제목 h1 40~48 / h2 28 / h3 20, 두 가지 굵기(400/500)만 사용
- 한/영 페이지는 동일 레이아웃, 영어 텍스트가 길어질 것을 고려해 고정 너비 지양

## 4. 레이아웃
- 최대 너비 1120px, 좌우 여백 모바일 16px / 데스크톱 24px
- 모바일 우선 반응형: 카드 그리드 1열 → 2열(md) → 3열(lg)
- 헤더: 로고(이름), 네비(Projects, Blog, About, Contact), 언어 전환(KO | EN), 모바일은 햄버거
- 섹션 간격 96px(데스크톱), 카드 라운드 10~12px, 그림자 없이 테두리로 구분

## 5. 화면별 구성
- **Home**: Hero(직군 라벨, 두 줄 헤드라인, 소개, CTA 2개) → 대표 프로젝트 3개 → Skills → 최근 글 3개 → 함께 일하기 → Footer
- **Projects**: 기술/종류 필터 칩 + 카드 그리드. 카드 = 썸네일, 제목, 한 줄 요약, 기술 태그
- **Project 상세**: 상단 미디어(영상/GIF/WebGL), 메타 정보 사이드(기간, 역할, 기술, 링크), 본문(문제와 해결 중심)
- **Blog**: 날짜순 리스트(제목, 날짜, 태그, 요약), 상세는 읽기 좋은 단일 컬럼(최대 720px), 코드 하이라이팅
- **About**: 자기소개 + 타임라인(학력, 활동, 수상)
- **Contact**: 이메일, GitHub, 이력서 다운로드

## 6. 컴포넌트 목록
Header, LangSwitch, Hero, Button(primary/ghost), ProjectCard, TagChip, FilterBar, SkillGroup, PostItem, Timeline, SectionTitle, MediaViewer, Footer

## 7. 인터랙션
- 최소한의 모션: 카드 hover 시 테두리 accent, 섹션 스크롤 진입 시 페이드(옵션)
- `prefers-reduced-motion` 존중
- 접근성: 명도 대비 확인(text/muted 모두 bg 위에서 AA 이상), 포커스 링 표시

## 8. 미결정
1. 포인트 컬러 최종 확정 (현재 민트 #6EE7C8, 대안: 보라/주황)
2. 로고/이름 표기 방식 (텍스트형 vs 심볼)
3. 라이트 모드 지원 여부
4. 프로젝트 상세에서 WebGL 임베드 vs 링크
5. Figma 시안 제작 여부 (코드 직행 가능)
