# 03. 기술스택

## 현재 세팅 (package.json 기준)
Vite 8, React 19, Tailwind CSS 4 (`@tailwindcss/vite`), ESLint 10. 언어는 JavaScript(JSX).

## 확정 스택
| 영역 | 선택 | 이유 |
|---|---|---|
| 빌드 | Vite | 이미 설정됨. `import.meta.glob`으로 콘텐츠 폴더 자동 수집 |
| UI | React 19 | 이미 설정됨 |
| 스타일 | Tailwind 4 | 이미 설정됨. `@theme`에 02-디자인의 컬러/폰트 토큰 정의 |
| 라우팅 | react-router (v7, `/ko/*`, `/en/*`) | 언어별 라우트 분리, 프로젝트/블로그 상세 경로 |
| 콘텐츠 | Markdown 파일 + frontmatter | 폴더에 파일을 추가하면 자동 반영 |
| 마크다운 렌더 | react-markdown + remark-gfm | 본문 렌더링 |
| 코드 하이라이팅 | rehype-highlight (가볍게) 또는 shiki | 블로그/프로젝트 코드 블록 |
| frontmatter 파서 | front-matter | 브라우저에서 동작(gray-matter는 Buffer 의존이라 제외) |
| SEO | react-helmet-async 또는 React 19 내장 `<title>`/`<meta>` | 페이지별 제목, OG 태그 |
| 폰트 | Pretendard(CDN 또는 self-host), JetBrains Mono | 디자인 문서와 동일 |
| 린트/포맷 | ESLint(설정됨) + Prettier | |

## 콘텐츠 자동화 구조
```
src/content/
  projects/ko/*.md   projects/en/*.md
  posts/ko/*.md      posts/en/*.md
  data/profile.ko.json, profile.en.json, skills.json, timeline.ko.json ...
public/
  media/projects/<slug>/...   (이미지, 영상, GIF)
  resume-ko.pdf, resume-en.pdf
```
- `import.meta.glob('/src/content/projects/ko/*.md', { query: '?raw', import: 'default', eager: true })`로 수집, 빌드 시점에 번들되므로 별도 서버 불필요
- 파일명 = slug. frontmatter로 제목, 요약, 기간, 역할, 기술[], 썸네일, 링크, featured, order, 날짜, 태그 지정
- 파일을 추가하고 저장만 하면 개발 서버에서 즉시 반영, 배포 시 포함
- 필수 필드 누락을 빌드 전에 잡는 검증 스크립트는 5단계에서 추가 검토

## 배포
- 정적 사이트이므로 **Cloudflare Pages 또는 Vercel 추천** (GitHub 연동, push 시 자동 배포, SPA 라우팅 지원, 무료 플랜 충분)
- GitHub Pages는 SPA 라우팅 때문에 404 fallback 설정이 추가로 필요
- 도메인은 선택 사항(처음엔 기본 도메인 사용 가능)

## 결정 사항과 보류
- **TypeScript**: 현재 JS로 세팅됨. 콘텐츠 스키마 안정성이 필요하면 도입 가능하지만, 1차는 JS 유지 권장
- **SSG/SSR(Next.js, Astro 등)**: 도입하지 않음. 요구사항이 React + Tailwind이고 콘텐츠가 정적이라 SPA로 충분. 단, 블로그 글이 검색에 노출되는 게 중요해지면 프리렌더링(`vite-react-ssg` 등)을 후속으로 검토
- **WebGL 게임 빌드 임베드**: iframe 방식(`public/games/<slug>/`)으로 처리 가능, 용량 큰 빌드는 외부 호스팅(itch.io 등) 링크로 대체
- **영상**: 짧은 클립은 mp4/webm을 직접, 긴 영상은 YouTube 임베드

## 추가 설치 예정 패키지
```
npm i react-router react-markdown remark-gfm rehype-highlight front-matter
npm i -D prettier
```
(설치는 5단계 개발 시작 시 진행)
