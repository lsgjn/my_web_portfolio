# 06. GitHub Pages 배포

- 저장소: `lsgjn/my_web_portfolio` (Pages를 무료로 쓰려면 public)
- 주소: `https://lsgjn.github.io/my_web_portfolio/`

## 코드에서 처리한 것
- `vite.config.js`: 빌드/preview는 `base: "/my_web_portfolio/"`, 개발 서버는 `"/"`
- `src/main.jsx`: `BrowserRouter basename`에 base 적용
- `src/functions/url.js`의 `withBase()`: `/media/...`, `/resume-ko.pdf` 같은 루트 기준 경로에 base를 붙임 (마크다운 이미지·링크, 썸네일, 미디어, 버튼)
- `.github/workflows/deploy.yml`: `main`에 push하면 빌드 → `404.html` 복사(새로고침 대응) → Pages 배포

## 처음 한 번만 할 일
1. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택
2. 로컬에서 git 초기화 후 push

```
git init -b main
git add .
git commit -m "Initial commit: portfolio site"
git remote add origin https://github.com/lsgjn/my_web_portfolio.git
git push -u origin main
```

push 후 저장소의 Actions 탭에서 배포 진행을 확인한다.

## 배포 후 확인
- `/my_web_portfolio/` → `/ko`로 이동
- `/my_web_portfolio/ko/projects/portfolio-site`에서 새로고침해도 열림
- `/my_web_portfolio/admin`은 404

## 개인 정보
이름, 소개, 이메일, GitHub, 이력서는 "아직 채우지 않음" 또는 빈 값이다. 이메일/GitHub/이력서가 비어 있으면 해당 버튼과 링크는 화면에 나오지 않는다. 관리자의 "프로필 · 이력" 탭에서 채운다.
